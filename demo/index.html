Try draft.inator

draft.inator adds the blocks writers expect (citations first) to Sveltia CMS, for sites whose pages live in a git repository. These pages run its real code in your browser. Nothing is sent anywhere.

In Sveltia CMSThe real editor, with the Cite and Figure blocks, on a sample site. Insert a figure, upload an image, cite a work. Changes stay in your browser. The Cite blockOpen a citation, change it in the form, and save it back, and see that nothing but its note changes. The build toolsKeep notes current, total the tags writers give, and make the works list, on a sample site.
