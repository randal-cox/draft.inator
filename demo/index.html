draft.inator

Try draft.inator

An article editor for sites whose pages live in a git repository: Markdown with citations and figures, a live preview, and the page's details, saved as a pull request. These pages run its real code in your browser. Nothing is sent anywhere.

Start here: the editor

A sample essay with its details (title, authors, topics, card image) above the text, citations and figures in it, and the page as readers will see it beside you. Change anything; Save says what it would write.
