The site's settings

Use the same style as the site's build. The notes and the works list both follow it.

1. Keep notes current: draft-inator notes

Every citation marker carries a note: so a person reading the raw file can tell what it cites. The check finds notes that are missing or out of date, and fails a pull request until they're refreshed.
