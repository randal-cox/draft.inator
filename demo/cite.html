The Cite block

Open a citation in the text, change it in the form, and save it back. This is the block's real code (src/blocks/citation.js). It's running in draft.inator's own forms (src/editor/forms.js), which draw the form from the block's field list, so you can try it without setting up a site.

    What to notice

    • Only the note changes. Open a citation and save it without touching the form: the marker comes back the same, except that its note: is set to the work's current description. Try the "Bell 1991" one.
    • Unknown options are kept. label:"chapter" isn't in the form, but it shows up under "Other options" and is written back where it was.
    • Directives are left alone. {citation endnote} isn't a citation of a work, so it isn't listed and can't be opened.
    • "Open and save every citation" runs the round-trip test the project runs on every corpus.

    The works and topics come from examples/sample-site/works.js, which draft-inator works makes from a citation.inator cache.
